# Machine Learning Case Studies

A collection of practical machine learning case studies and data science projects built with Python.  
This repository focuses on applying core ML workflows to real-world datasets, including data cleaning, exploratory data analysis, feature engineering, model training, evaluation, and result interpretation.

## Overview

This repository contains a set of independent machine learning projects that cover both classification and regression tasks.  
Each notebook demonstrates a complete workflow from raw data to model evaluation, using widely used Python libraries such as:

- `pandas`
- `numpy`
- `matplotlib`
- `seaborn`
- `scikit-learn`
- `tensorflow` (where applicable)

The goal of this repository is to build a strong practical portfolio in data science and machine learning while documenting the problem-solving process clearly.

## Projects

### 1. Decision Tree - Titanic
A classification project based on the Titanic dataset.

**Main tasks:**
- Data cleaning
- Handling missing values
- Encoding categorical features
- Building a decision tree classifier
- Evaluating model performance

**Goal:**  
Predict passenger survival using demographic and travel-related features.

---

### 2. California Housing Analysis
A regression project using the California housing dataset.

**Main tasks:**
- Exploratory data analysis
- Understanding housing feature distributions
- Preparing data for regression
- Training and evaluating prediction models

**Goal:**  
Predict house prices based on geographic and socio-economic features.

---

### 3. Boston Housing
A classic regression case study using the Boston housing dataset.

**Main tasks:**
- Data inspection and preprocessing
- Correlation analysis
- Regression model training
- Performance evaluation

**Goal:**  
Estimate housing values using property and neighborhood characteristics.

---

### 4. USA Real Estate
A real estate analysis project focused on U.S. housing data.

**Main tasks:**
- Dataset exploration
- Feature analysis
- Cleaning and transformation
- Model preparation and interpretation

**Goal:**  
Analyze patterns in real estate data and support price-related predictions.

---

### 5. Wine Quality
A classification/regression-style project on wine quality prediction.

**Main tasks:**
- Data analysis
- Feature distribution study
- Model training
- Quality prediction and evaluation

**Goal:**  
Predict wine quality based on physicochemical properties.

---

### 6. Mobile Price Classification
A multi-class classification project using mobile device specifications.

**Main tasks:**
- Feature analysis
- Data preprocessing
- Classification model development
- Accuracy comparison

**Goal:**  
Classify mobile phones into price ranges based on technical features.
